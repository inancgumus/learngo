# Шпаргалка: пишем первую программу на Go

Привет!

Для справки сохраните эту шпаргалку после того, как пройдёте лекции этого раздела.

Вы также можете распечатать её и следовать видео-лекциям этого раздела вместе с ней.

Приятного обучения!

---

## КОМАНДЫ КОМАНДНОЙ СТРОКИ:

* Перейти в каталог: `cd directoryPath`

* **WINDOWS:**

    * Показать файлы в каталоге: `dir`

* **OS X И LINUX:**

    * Показать файлы в каталоге: `ls`

## СБОРКА И ЗАПУСК ПРОГРАММ НА GO:

* **Собрать программу на Go:**

    * Находясь в каталоге программы, введите:
        * `go build main.go`

* **Запустить программу на Go:**

    * Находясь в каталоге программы, введите:
        * `go run main.go`

## ГДЕ ХРАНИТЬ ИСХОДНЫЕ ФАЙЛЫ?

* В любом каталоге, который вам нравится.

## ПЕРВАЯ ПРОГРАММА

### Создайте каталог
* Создайте новый каталог:
  * `mkdir myDirectoryName`
* Перейдите в этот каталог:
  * `cd myDirectoryName`

### Добавьте файлы с исходным кодом
* Создайте новый файл `code main.go`.
  * Это создаст файл в папке и откроет его в Visual Studio Code.
* Добавьте в него следующий код и сохраните.

```go
package main

import "fmt"

func main() {
    fmt.Println("Hi! I want to be a Gopher!")
}
```

### Запустите программу
* Наконец, вернитесь в командную строку.
  * Запустите так: `go run main.go`
* Если вы создадите другие файлы и хотите запустить их все, используйте команду:
  * `go run .`
