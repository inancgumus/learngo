## Где хранить исходные файлы, которые принадлежат одному пакету?
1. Каждый файл должен лежать в отдельном каталоге
2. В одном каталоге *CORRECT*


## Зачем в исходном файле Go нужна package clause (объявление пакета)?
1. Она нужна для импорта пакета
2. Она нужна, чтобы сообщить Go, что файл принадлежит пакету *CORRECT*
3. Она нужна для объявления новой функции

> **1:** Это делает оператор `import`.
>
>
> **3:** Это делает оператор `func`.
>
>


## Где нужно размещать `package clause` в исходном файле Go?
1. Как первый код в исходном файле Go *CORRECT*
2. Как последний код в исходном файле Go
3. Её можно разместить где угодно


## Сколько раз можно использовать `package clause` в одном исходном файле?
1. Один раз *CORRECT*
2. Ни разу
3. Несколько раз


## Какой вариант — корректное использование `package clause`?
1. `my package`
2. `package main`
3. `pkg main`


## Что верно?
1. Все файлы, принадлежащие одному пакету, не могут вызывать функции друг друга
2. Все файлы, принадлежащие одному пакету, могут вызывать функции друг друга *CORRECT*


## Как запустить несколько файлов Go?
1. go run *.*go
2. go build *go
3. go run go
4. go run *.go *CORRECT*

> **4:** Можно также вызвать так (если в одном каталоге лежат file1.go, file2.go и file3.go): go run file1.go file2.go file3.go
