## Где нужно хранить исходный код на Go?
* В любом месте на компьютере
* В $GOPATH
* В $GOPATH/src *CORRECT*

## Что означает $GOPATH?
* Это файл для среды выполнения Go
* Хранит исходные файлы Go и скомпилированные пакеты
* Это путь, по которому ходят гоферы

## Нужно ли задавать $GOPATH?
* Да
* Нет: он хранится на моём рабочем столе
* Нет: он хранится в моём пользовательском пути *CORRECT*

## Как можно вывести $GOPATH?
* С помощью команды `ls`
* С помощью команды `go env GOPATH` *CORRECT*
* С помощью команды `go environment`
