## Что такое область видимости (scope)?

- Исполняемый блок кода
- Видимость объявленных имён **CORRECT**
- Определяет, что запускать

```go
package awesome

import "fmt"

var enabled bool

func block() {
    var counter int
    fmt.Println(counter)
}
```

## Какое имя ниже имеет область видимости пакета?

1. awesome
2. fmt
3. enabled **CORRECT**
4. counter

> **3:** Верно. `enabled` объявлена вне функций, поэтому это имя с областью видимости пакета. Функция `block()` тоже имеет область видимости пакета; она тоже объявлена вне функций.

## Какое имя ниже имеет область видимости файла?

1. awesome
2. fmt **CORRECT**
3. enabled
4. block()
5. counter

> **2:** Верно. Имена импортированных пакетов имеют область видимости файла. И использовать их можно только в пределах того же файла.

## Какое имя ниже находится в области видимости функции block()?

1. awesome
2. fmt
3. enabled
4. block()
5. counter **CORRECT**

> **5:** Верно. `counter` объявлена внутри функции `block()`, поэтому она в области видимости функции block. Вне функции `block()` другой код её не видит.

## Может ли `block()` видеть имя `enabled`?

1. Да: оно в области видимости пакета **CORRECT**
2. Нет: оно в области видимости файла
3. Нет: оно в области видимости блока block()

> **1:** Весь код внутри одного пакета видит все имена, объявленные на уровне пакета.

## Могут ли другие файлы пакета `awesome` видеть имя `counter`?

1. Да
2. Нет: оно в области видимости пакета
3. Нет: оно в области видимости файла
4. Нет: оно в области видимости блока block() **CORRECT**

> **4:** Верно. Никакой другой код не видит имена внутри функции `block()`. Их видит только код внутри функции `block()` (и то лишь отчасти. Например: внутри блока код видит только переменные, объявленные до него.)

## Могут ли другие файлы пакета `awesome` видеть имя `fmt`?

1. Да
2. Нет: оно в области видимости пакета
3. Нет: оно в области видимости файла **CORRECT**
4. Нет: оно в области видимости блока block()

> **3:** Импортированные пакеты видит только тот же файл, а не другие файлы, независимо от того, в одном они пакете или нет.

## Что произойдёт, если объявить одно и то же имя в одной области видимости так:

```go
package awesome

import "fmt"

// объявлено дважды в области видимости пакета
var enabled bool
var enabled bool

func block() {
    var counter int
    fmt.Println(counter)
}
```

1. Новое объявленное имя переопределит предыдущее.
2. Так нельзя. Имя уже объявлено в области видимости пакета. *CORRECT*
3. Так нельзя. Имя уже объявлено в области видимости файла.

> **2:** Верно. Нельзя объявить одно и то же имя в одной области видимости. Если бы это было возможно, как бы вы к нему обращались снова? И к какому именно?

## Что произойдёт, если объявить одно и то же имя в другой области видимости так:

```go
package awesome

import "fmt"

// объявлено в области видимости пакета
var enabled bool

func block() {
    // тоже объявлено в области видимости блока
    var enabled bool

    var counter int
    fmt.Println(counter)
}
```

1. Новое объявленное имя переопределит предыдущее. *CORRECT*
2. Так нельзя. Имя уже объявлено в области видимости пакета.
3. Так нельзя. Имя уже объявлено в области видимости файла.

> **1:** На самом деле так можно объявить одно и то же имя во внутренних областях видимости. Область видимости `block()` находится внутри её пакета. Значит, она может обращаться к области видимости пакета (но не наоборот). Поэтому область видимости `block()` вложена в область видимости пакета. Значит, имя можно объявить снова. Оно переопределит имя из родительской области видимости. Оба имени могут существовать вместе. Посмотрите пример в репозитории курса, чтобы разобраться.
