# Разобранный пример программы на Go

```go
// package main — особый пакет
// он позволяет Go создать исполняемый файл
package main

/*
Это многострочный комментарий.

Ключевое слово import делает другой пакет доступным
  для этого .go "файла".

import "fmt" даёт вам доступ к функциональности пакета fmt
  здесь, в этом файле.
*/
import "fmt"

// "func main" — особенная функция.
//
// Go должен знать, с чего начать
//
// func main создаёт для Go точку старта
//
// После компиляции кода
// среда выполнения Go сначала запустит эту функцию
func main() {
	// после: import "fmt"
	// функция Println пакета "fmt" становится доступной

	// Посмотрите, как она выглядит, набрав в консоли:
	//   go doc -src fmt Println

	// Println — это просто экспортируемая функция
	//   пакета "fmt"

	// Экспортируемая = первая буква заглавная
	fmt.Println("Hello Gopher!")

	// Go не может вызвать функцию Println сам.
	// Поэтому её нужно вызвать здесь.
	// Автоматически вызывается только `func main`.

	// -----

	// Go поддерживает символы Unicode в строковых литералах
	// А также в исходном коде: KÖSTEBEK!
	//
	// Потому что: литерал ~= исходный код
}
```
