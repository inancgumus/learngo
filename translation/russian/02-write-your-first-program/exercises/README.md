2. **Поздоровайтесь с самим собой.**

    1. Соберите программу с помощью `go build`

    2. **Отправьте её другу**

       У него должна быть та же операционная система.

       Например, если вы используете Windows, то и у него должен быть Windows.

    3. **Отправьте программу другу с другой операционной системой**

       Для этого скомпилируйте программу под его операционную систему.

       **Создать исполняемый файл для OSX:**
       `GOOS=darwin GOARCH=386 go build`

       **Создать исполняемый файл для Windows:**
       `GOOS=windows GOARCH=386 go build`

       **Создать исполняемый файл для Linux:**
       `GOOS=linux GOARCH=arm GOARM=7 go build`

       **Полный список смотрите здесь:**
       https://golang.org/doc/install/source#environment

       **ЗАМЕЧАНИЕ:** Если вы используете командную строку или PowerShell, возможно, понадобится такая запись:
       `cmd /c "set GOOS=darwin GOARCH=386 && go build"`

3. **Вызовите [Print](https://golang.org/pkg/fmt/#Print) вместо [Println](https://golang.org/pkg/fmt/#Println)** и посмотрите, что получится.

4. **Вызовите [Println](https://golang.org/pkg/fmt/#Println) или [Print](https://golang.org/pkg/fmt/#Print) с несколькими значениями**, разделяя их запятыми.
