# Изучаем Go на примерах, упражнениях и задачах

Лучший способ учиться — делать. В этом репозитории вы найдёте тысячи примеров, упражнений и задач на Go. Изначально я создал этот репозиторий для своего курса **[Go: Bootcamp Course](https://www.udemy.com/course/learn-go-the-complete-bootcamp-course-golang/?referralCode=5CE6EB34E2B1EF4A7D37)**. Позже я добавил много упражнений и захотел, чтобы каждый программист, ещё не записавшийся на курс, тоже мог учиться бесплатно. Так и появился этот репозиторий. Приятного обучения.
