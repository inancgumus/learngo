## Какой из ключевых слов ниже нужен, чтобы объявить пакет?
```go
package main

func main() {
}
```
1. func
2. package *CORRECT*
3. fmt.Println
4. import

> **1:** Ключевое слово func используется, чтобы объявить новую функцию.
>
>
> **2:** Верно! Ключевое слово package позволяет объявить пакет для файла Go.
>
>
> **3:** Это не ключевое слово, это функция пакета fmt.
>
>
> **4:** Ключевое слово import используется, чтобы импортировать пакет.
>
>


## Для чего в следующей программе используется package main?
```go
package main

func main() {
}
```
* Чтобы создать библиотечный пакет
* Чтобы корректно завершить программу
* Чтобы создать исполняемую программу на Go *CORRECT*


## Для чего в следующей программе нужна func main?
```go
package main

func main() {
}
```
1. Она объявляет пакет с именем main
2. Она позволяет Go начать выполнение программы *CORRECT*
3. Она печатает сообщение в консоль

> **1:** функция main не создаёт пакет.
>
>
> **2:** Верно. Go автоматически вызывает функцию main, чтобы выполнить программу.
>
>
> **3:** Она ничего не печатает (по крайней мере, напрямую).
>
>


## Для чего в следующей программе нужен import "fmt"?
```go
package main
import "fmt"

func main() {
    fmt.Println("Hi!")
}
```
1. Он печатает "fmt" в консоль
2. Он объявляет новый пакет с именем "fmt"
3. Он импортирует пакет `fmt`; так вы можете использовать его возможности *CORRECT*

> **1:** `fmt.Println` печатает сообщение, а не `import "fmt"`.
>
>
> **2:** Это делает ключевое слово `package`, а не `import`.
>
>
> **3:** Да. Например, после импорта пакета fmt вы можете вызвать его функцию Println, чтобы напечатать сообщение в консоль.
>
>


## Какое ключевое слово используется, чтобы объявить новую функцию?
* func *CORRECT*
* package
* Println
* import


## Что такое функция?
1. Это как мини-программа. Это переиспользуемый и исполняемый блок кода. *CORRECT*
2. Она позволяет Go выполнить программу.
3. Она позволяет Go импортировать пакет с именем function.
4. Она печатает сообщение в консоль.

> **2:** Для этого Go ищет package main и func main. Функция сама по себе этого не делает.
>
>
> **3:** Это делает ключевое слово `import`.
>
>
> **4:** Например, это делает `fmt.Println`.
>
>


## Нужно ли вызывать функцию main самому?
1. Да, чтобы я мог выполнить свою программу.
2. Нет, Go вызывает функцию main автоматически. *CORRECT*

> **1:** Нет, вызывать функцию main не нужно. Go выполняет её автоматически.
>
>


## Нужно ли вызывать функцию, чтобы она выполнилась?
_(кроме func main)_
1. Да, чтобы Go мог выполнить эту функцию. *CORRECT*
2. Да, чтобы Go мог выполнить мою программу.
3. Нет, Go вызывает функции автоматически.

> **1:** Верно. Функцию нужно вызывать самому. Go не выполнит её автоматически. Автоматически Go вызывает только функцию main (и некоторые другие функции, о которых вы ещё не знаете).
>
>


> **2:** Это задача только `func main`. `func main` всего одна.
>
>


> **3:** Go не вызывает автоматически ни одну функцию, кроме func main (и некоторых других функций, о которых вы ещё не знаете). Поэтому все функции, кроме main, нужно вызывать самому.
>


## Что напечатает следующая программа?
```go
package main

func main() {
}
```
1. Она печатает сообщение в консоль
2. Это корректная программа, но она ничего не печатает *CORRECT*
3. Это некорректная программа

> **1:** Она не печатает сообщение. Для этого можно использовать функцию fmt.Println.
>
>


> **2:** Да, это корректная программа, но поскольку в ней нет fmt.Println, она ничего не печатает.
>
>


> **3:** Это корректная программа. В ней используется ключевое слово package и есть функция main. Значит, это допустимая и исполняемая программа на Go.
>
>


## Что напечатает эта программа?
```go
package main

func main() {
    fmt.Println(Hi! I want to be a Gopher!)
}
```
* Hi! I want to be a Gopher!
* Она ничего не печатает
* Эта программа некорректна *CORRECT*

> **1:** Она не передаёт сообщение в Println в двойных кавычках. Должно быть так: fmt.Println("Hi! I want to be a Gopher")
>
>


> **3:** Она не импортирует пакет "fmt". Также см. #1.
>
>


## Что напечатает эта программа?
```go
package main
import "fmt"

func main() {
    fmt.Println("Hi there!")
}
```
* Hi there! *CORRECT*
* fmt
* Эта программа некорректна; она импортирует не тот пакет или в ней нет функции `Println`

> **2:** import "fmt" импортирует пакет `fmt`; так вы можете использовать его возможности.
>
>
> **3:** На самом деле эта программа корректна.
>
